# Phantom-Ship-Var-Hastra-Start-on-Galaxy-on-Fire-2
I've custom made this saved game to allow the user to start the game with the original ship The Phantom that is in the first pirate battle and cutscene that Keith pilots and that Gunant later claims as salvage rights. Now you can buy this ship back in the hanger shop at Var Hastra station at the start of the game. I've also adjusted the credits so you already have the money to buy the ship at the start of the same. You will also have the option of keeping the Betty ship in the Kaamo Club for later or selling it. Enjoy!
